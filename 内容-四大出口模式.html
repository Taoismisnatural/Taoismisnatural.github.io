9610 / 9710 / 9810 / 1039 有什么区别？我该选哪个（2026）

高频问答四种监管代码权责不同、不可混用

很多卖家栽在这：四种监管代码边界彼此不通用，选错要么退税退不下、要么补税罚款。本文用一张对比表 + 判断逻辑，帮你对号入座。

先记住一句话

无票免税 → 只看 9610；能拿到专票 → 走 9710 / 9810 退税；从批发市场拿货 → 走 1039。 这是选型的起点，后面再按细节排除。

四种模式一表看懂

代码业务形态有无无票免税最适合谁关键注意
9610 零售直邮小包直发海外消费者有（综试区登记出口信息）无进项专票的中小卖家唯一可适用综试区无票免税；单票一般≤5000元；要登记+备案+按期申报
9710 B2B直接出口线上批量卖境外企业无（须完整进项专票）有专票、批量批发无票出口会被视同内销补增值税
9810 海外仓出口先备货海外仓、海外零售无（须专票；离境可预退税）大卖、看重现金流周转须持专票；区分已销/未销核算，否则追回预退税款
1039 市场采购市场集聚区多品类零散采购出口增值税免征不退；个税可核定无发票、多SKU小微卖家须在试点集聚区内；单票货值与地域有各自上限

怎么判断你该选哪个（三问）

  1. 你能开到进项专票吗？能 → 优先走退税类（9710/9810）；不能 → 看下面可申报免税的路径（9610/1039）。
  2. 你的货怎么发？小包直邮 → 9610 候选；海外仓备货 → 9810 候选；批量卖给境外企业 → 9710；从批发市场/集市拿货 → 1039 候选。
  3. 注册地在综试区吗？走 9610 无票免税，第一道硬门槛就是注册地在跨境电商综合试验区内。
最实用的一步：别只靠记，直接拿你的发货/开票情况过一遍我们的「4分钟合规自查」，系统会按你的输入给出最可能适用模式，并标出风险。

三个易踩的坑

  • 有票硬走无票免税：能取得进项专票却硬套 9610 无票免税，属模式错配，是稽查重灾区。
  • 无票强行走退税：没发票硬走一般贸易/9710 退税，会被视同内销补缴增值税。
  • 拿批发市场货去套小店对应不上：1039 有明确的试点集聚区与单票上限，先确认自己是否符合。
红线：四种代码不可混用、不可随意切换；未落户综试区却套用无票免税，是当前高发稽查教训。
