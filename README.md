## 二、执行顺序：从 0 到第一笔成交

### 阶段 0 · 起量前（一次性打底）
- [ ] 在隐私政策"联系我们"补上你的主体信息/微信（本地改后重新推 GitHub）
- [ ] 把 partners / coop-card 里的**分成比例占位改成你谈定的数字**（别让 20%~30% 变成对方砍价基准）
- [ ] 想清楚 1 个试点城市 + 1 个品类（先小后大）

### 阶段 1 · 找机构（BD，最快通路，先做）
- [ ] 用 `⑤BD手册` 的"过滤清单"先筛 3~5 家"有跨境经验 + 本地 + 老板能拍板"的机构
- [ ] 先给意向机构发 `② partners.html` 链接（官方方案）
- [ ] 或发 `③ coop-card.html` 长图（微信/邮件群发用）
- [ ] 建联后用 `⑤BD手册` 的话术谈，**先免费导 3 条促成一单真实成交**，记下成交率
- [ ] 谈成即签一页纸《合作确认函》（分成口径/结算周期/责任边界）

### 阶段 2 · 让漏斗进水（SEO/内容，慢但放长线）
- [ ] 继续补长尾内容（已 10 篇，可再扩），保持"官网能搜到/能呆得住"
- [ ] 有条件再上自定义域名 + 备案，提升收录与信任

### 阶段 3 · 日常运营（打卡节奏）
- [ ] **每日**：打开 `④对账后台`，看有没有新线索；有新线索 → 按城市派给对应机构
- [ ] **每周**：回访在谈机构；催"已成交"的分成核销；更新《BD 进度表》
- [ ] **每成交**：在后台把「成交金额 / 我的分成」记进待结算 → 到账后标记「已结算」

---

## 三、一条线索从进来到收钱（完整链路清单）
- [ ] 卖家在 `①官网` 评估，勾选"同意转介"并留资
- [ ] 线索写入 Cloudflare Worker → Supabase（能进库）
- [ ] 你在 `④后台` 看到它（带编号）
- [ ] 派给机构（后台/手动记 assigned_to）
- [ ] 机构联系卖家并成交
- [ ] 后台记「成交 + 我的分成」→ 进入待结算
- [ ] 到账后标记「已结算」，完成核销
