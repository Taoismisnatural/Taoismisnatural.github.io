AXION API 参考

可验证信号平台的公开接口。所有数据与官网同源同口径：600 天真实回测常量、本机探针实时成交 CSV、Binance USDC-M 实时行情。公开接口无需注册即可调用。

BASE URL
http://127.0.0.1:5177

01鉴权与密钥

公开接口无需鉴权，可匿名读取。Pro 专属接口（完整信号参数 / SSE 实时流）需要订阅密钥：在请求头 X-AXION-KEY 或 URL 参数 ?key= 传入 AXK-…。密钥随订阅开通下发，到期自动失效。

# 带密钥的 Pro 接口示例
curl "http://127.0.0.1:5177/api/sub/status" \
  -H "X-AXION-KEY: AXK-xxxxxxxx"

02错误与限速

API 错误统一返回 JSON：{"ok": false, "error": "描述"}，状态码 400/401/404/429/500。订阅提交接口按 IP 限速：10 分钟窗口最多 8 次。若命中返回 429。

# 错误响应示例（404）
{"ok": false, "error": "接口不存在"}

03数据口径

诚实口径：回测为触价即成交（乐观），真实执行按探针实测折价；pnl1x 为 1x 杠杆、已扣手续费与资金费；TBSI 为近两根 K 线主动买入占比（klines 第 9 字段），<0.55 为高置信标记。净值类字段全部保留原始小数，前端展示四舍五入。

04实时行情

GET/api/quotes行情 · 8s 缓存

6 币深流动性池 + 观察池的 Binance USDC-M 实时行情，失败币价格置空（不编造）。

示例
curl "http://127.0.0.1:5177/api/quotes"
[{"sym":"BTCUSDC","short":"BTC","price":78169.3,"chg24h":2.45},
 {"sym":"ETHUSDC","short":"ETH","price":2183.41,"chg24h":-1.12}, …]
GET/api/quotes/brief行情 · sparkline

每币近 12h 收盘序列（15m×48），用于迷你走势图。查询参数 ?interval=&limit= 可选。

示例
curl "http://127.0.0.1:5177/api/quotes/brief" | jq '.symbols[0].closes | length'

05探针统计

GET/api/summary信号 · 30s 缓存

探针总记录、mom 三规则已平、触价率、TBSI 标记数、单笔平均盈亏（1x 口径）。

curl "http://127.0.0.1:5177/api/summary"
{"total": 1234, "mom_closed": 456, "touch_rate": 18.5, "pnl1x_avg": 0.042, …}
GET/api/signals信号 · 公开脱敏

最近真实成交信号（公开口径：隐藏精确挂单价）。参数 ?n= 控制条数（默认 15）。Pro 订阅可获取含完整参数的信号流（见 /api/pro/stream）。

响应字段
字段说明
ts / sym / side时间戳（UTC+8）· 币对 · LONG|SHORT
tf周期：15m / 30m / 1h
entry公开口径取 "-"；Pro 显示精确回撤挂单价
statustp（止盈）/ stop（止损）/ expire（超时）/ 挂单中
pnl / tbsi1x 盈亏 · TBSI 订单流标记
curl "http://127.0.0.1:5177/api/signals?n=5"
GET/api/equity业绩 · 600d 回测

16 个月真实回测输出：1x/2x 权益、月度收益、CAGR/终值/最大回撤，以及 风险调整指标 risk（Sharpe / Sortino / Calmar / 盈利月占比 / 最大连亏 / 回撤修复期，月级口径）。

curl "http://127.0.0.1:5177/api/equity" | jq '.risk'
{"sharpe_1x": 1.94, "sortino_1x": 9.19, "calmar": {"1x": 7.4, "2x": 10.1},
 "win_months": "10/16", "max_losing_streak": 4,
 "max_dd_recovery_months": 6, "recovery_span": "25-09 → 26-05"}
GET/api/equity/real业绩 · 探针真实模拟盘

mom 三规则真实虚拟成交的 1x 复利权益曲线：逐笔时间戳、累计权益、胜/负笔数与盈亏合计。可用于与回测折价对账。

curl "http://127.0.0.1:5177/api/equity/real" | jq '{labels: (.labels|length), finish: .pnl.finish}'

06审计台账

GET/api/analytics审计 · JSON

全量真实事件（含亏损）与台账统计：胜率、盈亏合计、按月胜率、等权累计。删不掉历史，盈亏都摆着。

curl "http://127.0.0.1:5177/api/analytics" | jq '.stats'
GET/api/analytics/export.csv审计 · CSV 导出

全量台账 CSV（时间戳齐全），用于本地留档、Excel/notebook 二次分析。字段：ts,sym,rule,tf,side,entry,exit,tp,sl,status,pnl1x,tbsi。

curl "http://127.0.0.1:5177/api/analytics/export.csv" -o axion_ledger.csv

07平台健康

GET/api/health健康 · 存活

存活探针：{"ok": true, "ts": "…"}。可用于监控告警（UptimeRobot 等）。

GET/api/diag健康 · 深度诊断

探针数据新鲜度（probe_age_h，>2h 即异常）、CSV 数量、数据库连通、活跃订阅、推送引擎心跳（最近 12 事件）与 Pusher 诊断。

curl "http://127.0.0.1:5177/api/diag" | jq '.probe_age_h, .db_ok'

08订阅（Pro）

POST/api/subscribe订阅 · 人工确认制

提交订阅申请，返回订单号、USDT-TRC20 收款地址与核验码；免费观察档即时下发订阅密钥。限速 8 次/10 分钟。

请求体

curl -X POST "http://127.0.0.1:5177/api/subscribe" \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","plan":"observe"}'
GET/api/sub/status订阅 · 状态自查

凭订阅邮箱 + 密钥查询状态：档位、到期时间、即将到期提醒。参数 ?email=&key=。

curl "http://127.0.0.1:5177/api/sub/status?email=you@example.com&key=AXK-xxxx"
GET/api/pro/stream订阅 · SSE 实时信号流

Pro 专属：EventSource/SSE 实时流，推送 mom 三规则的完整参数信号（精确挂单价、TP/SL、失效条件、建议权重、TBSI 标记），支持自动跟单机器人直接消费。参数 ?key=AXK-…。

# Node / 任意语言 SSE 消费示意
const es = new EventSource('http://127.0.0.1:5177/api/pro/stream?key=AXK-xxxx');
es.onmessage = e => console.log(JSON.parse(e.data)); // {ts, sym, side, tf, entry, tp, sl, …}
开发者合规提示：接口仅用于个人订阅者自用跟单，禁止转售、再分发信号流。自动化执行请自行承担滑点与擦单风险，并遵守交易所 API 规范。详见服务条款。
