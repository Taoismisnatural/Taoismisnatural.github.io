跟单接入指引

AXION 提供三种跟单方式：网页控制台（人工跟单）、SSE 实时流（轻量自动）、Webhook 推送（机构档自动执行）。三种方式共用同一数据口径与订阅密钥鉴权。

0. 前置条件

订阅密钥（AXK-…） — 专业跟单档以上有效。免费观察档密钥仅可查看公开披露数据。用途：?key= 或请求头 X-AXION-KEY。
到期后自动失效（返回 401），续费后原密钥继续有效。

1. 网页控制台（最快上手）

首页顶部「控制台」区块输入邮箱 + 密钥 → 实时信号流即刻连接（SSE），无需写代码。

2. SSE 实时流（推荐自动跟单）

服务端推送事件，浏览器和新手脚本友好，断线自动重连（retry: 15000）。

端点：GET /api/pro/stream?key=AXK-…
鉴权：密钥错误或已过期返回 401。
# Python：使用 requests + 文本流
import requests
import json

url = "http://<your-host>/api/pro/stream"
r = requests.get(url, params={"key": "AXK-…"}, stream=True, timeout=(5, 300))
for line in r.iter_lines():
    if line and line.startswith(b"data: "):
        ev = json.loads(line[6:])
        print(ev["sym"], ev["side"], ev["entry"], ev["tp"], ev["sl"])
// 浏览器：EventSource 自动重连
const es = new EventSource(`/api/pro/stream?key=${key}`);
es.onmessage = e => { const ev = JSON.parse(e.data); console.log(ev); };

3. Webhook 推送（机构档自动执行）

订阅开通后，在管理端维护该订阅的 webhook_url。每当有新信号，平台会 POST 以下 JSON 到你的端点（失败自动告警日志，不影响其他推送）。

幂等提示：每条信号唯一键为 ts + sym + rule。请在你的执行端按该键去重，避免同一信号重复下单。
// POST https://your-bot.example/webhook 请求体示例
{
  "type": "signal",
  "data": {
    "ts": "2026-09-01 12:26:10",
    "sym": "BTCUSDC",
    "rule": "mom1h_l",
    "tf": "1h",
    "side": "LONG",
    "entry": 78655.7,
    "tp": 4.0, "sl": 1.2,
    "status": "tp",
    "weight": 0.25,
    "reason": "1h 连续 2 根上涨动量触发 1.0% …",
    "invalidate": "止损 1.2% 触发或持仓超 4h 即失效"
  }
}

建议在 webhook URL 中自带密钥参数（如 https://host/hook?token=xxx），平台不额外加密，端口你自己鉴权。

4. 信号字段说明

字段含义说明
ts信号时间戳YYYY-MM-DD HH:MM:SS
sym币种USDC 永续交易对，如 BTCUSDC
rule / tf规则 / 周期mom15_l / 15m；30m；1h 三周期宽码头
side方向LONG / SHORT
entry / exit回撤挂单价 / 离场价null 表示未成交/未离场
tp / sl止盈 / 止损（%）相对挂单价，如 4.0 / 1.2
status状态open / tp / stop / expire / timeout
pnl1x盈亏1x 口径盈余百分比，已扣手续费与资金费
tbsi订单流指标数值越小信号越强（<0.55 高置信）
weight建议权重0~1，单币 Kelly 上限 25%
reason / invalidate触发理由 / 失效条件供人工与日志审计

5. 温馨提示与风险

  • 信号仅供跟单参考，不构成投资建议；请在理解清算与资金费后再使用杠杆。
  • 自动执行前先用最低仓位跑通链路，核对滑点与去重逻辑。
  • 任何密钥泄露风险自担：请勿将订阅密钥提交到公开仓库或第三方平台。
  • 组合级熔断建议：仿照 eToro「跟单止损 CSL」，建议为整个跟单组设定回撤阈值（默认 40%），触及即整体退出；平台信号侧：单月熔断 30%、连亏 4 笔冷却 2 周。
